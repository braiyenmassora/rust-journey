# Rust Journey

A personal journey of learning Rust, one exercise at a time.

## Exercises

| File | Topic |
|---|---|
| `src/exercise/hello_rust.rs` | Functions and the `println!` macro |
| `src/exercise/variables.rs` | Variables, constants, shadowing, and basic types |

## Getting Started

Requires [Rust](https://www.rust-lang.org/tools/install) (includes `cargo`).

```bash
git clone https://github.com/braiyenmassora/rust-journey.git
cd rust-journey
cargo run
```

## Learning Resources

- [The Rust Programming Language](https://doc.rust-lang.org/book/)
- [Rustlings](https://github.com/rust-lang/rustlings)

## Notes

- Each exercise is a module in `src/exercise/`, called from `src/main.rs`.
- Code comments are written in English to practice technical writing.
